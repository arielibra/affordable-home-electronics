# Where these files came from

| File | Source | Licence of the file |
| --- | --- | --- |
| visa, mastercard, amex, discover, paypal | `payment-icons` (muffinresearch), the "flat" set | MPL-2.0 |
| apple-pay, google-pay | glyph from `simple-icons`, set on a white plate here | CC0-1.0 |

A licence on the file is not a licence on the trademark. Displaying these is
fine because the shop genuinely accepts every one of them — that is exactly
what an acceptance mark is for.

For strict brand compliance the networks want their own current artwork, and
American Express and Discover issue theirs to accepting merchants directly.
Swapping any of these later means replacing the file and nothing else: same
names, same folder. See `brand/payment-marks/README.md`.
