# Affordable Home Electronics brand files

| File | Use it for |
|---|---|
| `logo-stacked.png` | The primary lockup. Signage, letterhead, anything with room. |
| `logo-horizontal.png` | One line of type. Email signatures, invoices, wide banners. |
| `logo-mark.png` | The cart on its own. Social avatars, stickers, a shirt pocket. |
| `logo-reversed.png` | White on blue. Van doors, dark print, the site footer. |

| `favicon.svg` | The browser tab icon. |

## Clear space and minimum size

Leave clear space around the lockup equal to the height of one wheel. Do not
place it below 24px tall for the stacked version or 18px for the mark alone.
Below about 40px the six lenses stop resolving, so the website switches to a
simplified version of the mark without them; a printer should do the same.

## Do not

Recolour it, add a shadow or bevel, stretch it, rotate it, outline the type, or
set the three words in a different typeface. The type is Geist Semibold.
